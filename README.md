<h1> System Informasi SPP </h1>
<p>
Aplikasi sederhana ini dibuat sebagai alat bantu Admin ataupun User untuk melakukan peminjaman buku bagi user dan Admin untuk mengelola data user, peminjam, maupun data buku.
</p>


<h4>Teknologi</h4>
<ul>
  <li>php native</li>
  <li>mysql</li>
  <li>bootstrap 5</li>
</ul>

<h4>Fitur</h4>
<ul>
  <li>Dashboard</li>
  <li>Data buku</li>
  <li>Data kategori</li>
  <li>Data users</li>
  <li>History</li>
</ul>


<h4>Roles</h4>
<ul>
  <li>Super Admin</li>
  <li>Admin</li>
  <li>Siswa</li>
</ul>
